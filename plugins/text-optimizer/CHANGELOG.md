# Changelog

## 2.0.0 (2026-10-10)

- Renamed from text-flags to text-optimizer. Install it from the marcovrinssen marketplace as `text-optimizer@marcovrinssen`. `/text` and every flag work as before.

## 1.0.0 (2026-10-08)

- First release. Flag-driven text transforms. Load with /text, then start a message with a flag to correct, translate, sharpen, polish, soften, shorten or list text, or to build prompts for Claude and image models.
