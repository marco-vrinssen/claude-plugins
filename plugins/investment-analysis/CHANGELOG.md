# Changelog

## 2.0.0 (2026-10-28)

- Renamed from financial-analysis, because it does investment research, not financial statement analysis. The command is now `/investment-analysis`.

## 1.0.0 (2026-10-27)

- First release. Investment research for private investors in Germany. Turns a ticker, ISIN, ETF, theme, pitch or stock tip into a sourced report with a buy, watch or avoid verdict.
