# Changelog

## 2.2.0 (2026-10-12)

- `-c` fixes typos only. Wording, tone, style, casing, punctuation, dashes and abbreviations stay exactly as written.

## 2.1.0 (2026-10-10)

- `-pp` asks its open questions in Claude Code's question dialog, with options to pick and a `Leave open` choice that hands a point to the executor. Questions fall back to a numbered text list where the dialog is missing, fails or runs without a user, and for answers too long for its field, such as a pasted example.

## 2.0.0 (2026-10-10)

- Renamed from text-flags to text-optimizer. Install it from the marco-vrinssen marketplace as `text-optimizer@marco-vrinssen`. `/text` and every flag work as before.

## 1.0.0 (2026-10-08)

- First release. Flag-driven text transforms. Load with /text, then start a message with a flag to correct, translate, sharpen, polish, soften, shorten or list text, or to build prompts for Claude and image models.
