# marcovrinssen

Claude Code plugin marketplace by Marco Vrinssen. Each plugin lives in its own repo.

| Plugin | Does |
|---|---|
| [text-optimizer](https://github.com/marco-vrinssen/text-optimizer) | flag-driven text transforms: correct, translate, sharpen, shorten, build prompts |
| [mdr-check](https://github.com/marco-vrinssen/mdr-check) | flags health marketing copy that could count as a medical claim under EU MDR, HWG and UWG |
| [video-reader](https://github.com/marco-vrinssen/video-reader) | reads YouTube videos through transcript, chapters and frames |

## Install

```
/plugin marketplace add marco-vrinssen/marcovrinssen
/plugin install text-optimizer@marcovrinssen
```

Swap in any plugin name from the table.
