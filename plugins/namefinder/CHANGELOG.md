# Changelog

## 1.1.0 (2026-10-29)

- The skill carries its own name logic: borrow a word from a distant field, keep it short, repeat few vowels, pair one hard and one soft consonant, clean edges, a balanced shape on the page, one transform when needed.
- Letters the brief fixes, such as a start or an end, stay in every name.
- It no longer reads an Apple Notes list and runs no brand, domain or handle checks. It returns names, notes and a top 3 only.

## 1.0.0 (2026-10-27)

- First release. Generates brand, product, project and character names from sound symbolism, tuned to your taste.
