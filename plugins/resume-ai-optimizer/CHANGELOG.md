# Changelog

## 2.0.0 (2026-10-28)

- The skill is renamed from resume to resume-ai-optimizer to match the plugin, so the command is `/resume-ai-optimizer` instead of `/resume`.

## 1.0.0 (2026-10-12)

- First release. Optimizes resumes for AI-screened hiring along five rules: readable for parsers, obvious fit without keyword stuffing, AI only for wording, impact in numbers, AI skills proven. Ships `/resume` and a PDF check script.
